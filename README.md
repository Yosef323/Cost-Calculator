# Wall Painting Cost Calculator

A simple Python script to calculate the area of a wall and the total cost of painting it.

## How it works
1. The user enters the length and width of the wall.
2. The user enters the price of painting per square meter.
3. The script calculates the total area of the wall (Length × Width).
4. The script calculates the total cost (Area × Price per square meter).
5. Finally, it displays the total area and the final cost.

## How to use
1. Run the `Cost_Calculator.py` file.
2. Enter the required numbers when prompted.
